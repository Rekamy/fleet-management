# BRS

## Modules

Kajian BRS

1. Modul Pengurusan Kenderaan
    a. Permohonan
        i. Tempahan Kenderaan
        ii. Penyelenggaraan Kereta
        iii. Kenderaan Kereta Rasmi Jawatan (KRJ)
        iv. Kad Inden

2. Modul Pengguna
    a. Pengurusan pengguna (Create, Update, Update, Delete, Inpersonate)
    b. Kebenaran Capaian untuk pengguna
    c. Pengguna Kali Pertama
    d. Lupa Kata laluan

3. Modul Pentadbiran
    a. Lookup /CRUD
        i. Jawatan
        ii. Status Permohonan
        iii. Pembuat Kereta
        iv. Syarikat
        v. Model Kenderaan
        vi. Kategori Kenderaan
        vii. Kategori Jenis Kenderaan
        viii. Lokasi Menunggu
        ix. Jenis Kenderaan (lori, bas)
        x. Tujuan Mesyuarat:
            a. Mesyuarat       Priority : 6
            b. Kursus/Latihan   Priority : 7
            c. Lawatan Tapak       Priority : 8
            d. Pengauditan     Priority :  5
            e. Pemandu Ganti (Jusa ke Atas)     Priority : 1
            f.  Pemandu Gunasama (untuk Jawatan Jusa C sahaja dan mempunyai Kereta Rasmi Jawatan (KRJ))   Priority : 2
            g.  Penghantaran Barang    Priority : 3
            h. Urusetia Mesyuarat / Kursus / Latihan / Majlis    : Priority : 4
            i. Penyelenggaraan KRJ/Kereta Jawatan    : Priority : 10
            j.  Lain-lain : Masukkan catatan    : Priority : 9

    b. Pendaftaran/kemaskini maklumat
        i. Kenderaan

            2. Pelantikan pegawai perolehan
        ii. Jadual Harian Pemandu
